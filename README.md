# VORNEX Site Starter

Responsive VORNEX frontend + Node/Express başlangıç iskeleti.

## Çalıştır
npm install
cp .env.example .env
npm start

Tarayıcı: http://localhost:3000

Not: Frontend şu an demo verileri kullanır. Gerçek ödeme ve SmsOnay entegrasyonu sonraki aşamada sunucu tarafına eklenmelidir. API anahtarı frontend'e koyulmamalıdır.
